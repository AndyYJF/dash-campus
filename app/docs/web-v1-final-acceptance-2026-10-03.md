## 5. 日常运行与操作

独立桥接配置 `/etc/dash-campus/campus-bridge.env`；wrapper `/usr/local/libexec/dash-campus-campus-bridge`；systemd 服务 `dash-campus-campus-bridge.service`，timer 每 10 分钟。不要同时设置额外 cron。凭证放环境文件，网络请求用 Bearer；不放 URL，不打印 token。

管理员把需要的命令保存为脚本再执行。维护前：

```bash
systemctl stop dash-campus-campus-bridge.timer dash-campus-campus-bridge.service
docker compose stop web worker
```

按 [部署说明](deploy.md) 备份、迁移或恢复。升级完成、health 正常并确认非恢复暂停后启动 timer。恢复则先只启动 web 核对，确认旧实例和所有旧桥接都停止，再执行 `scripts/resume-after-restore.sh --yes-old-instance-stopped`，启动 worker 和 timer。不要仅恢复镜像，也不要在 hold 尚未解除时启动外部轮询。

目前生产 web 健康、worker 运行且重启次数均 0；心跳、外键与 SQLite 检查正常。最后轮询成功、timer 活跃。主人可继续填写方向/目标、可用时间和周重点，按“行动→记录→成果→回顾”使用；系统不会根据尚未填写的数据虚构状态。周期摘要及自动探索按主人设置启用。
