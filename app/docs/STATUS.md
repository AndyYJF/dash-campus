## 4. 必须保留的边界

单用户自部署，Web优先，自研有限步骤Agent；不换框架。Todo所有数据/附件/配置/服务/同步只读，Dash派生状态不回写源。独立开发库、向前迁移、完整导出恢复；不因允许重建Dash就直接清生产。

秘密与生产连接信息不进仓库。没有生产访问能力也可实现本地业务；后续部署须取得适用授权及新鲜备份/回滚证据，不能盲目恢复schema16旧备份到schema23或后续版本（当前代码要求 schema 34）。
