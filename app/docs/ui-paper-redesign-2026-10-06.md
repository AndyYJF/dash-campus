# 界面改版：纸面/手册风（2026-10-06）

主人的四个决定：风格取“安静的纸面/编辑风”；Agent 输入“底部细条，点开才展开”；“全部页面都重做”；桌面与手机“同等重要，各自设计”。本页记录改了什么、凭什么说它可用、还没做什么。改版经 PR #4 合入 `main`，主人已部署 `9c8c33d`；之后的本周网格修正见文末。

## 设计要点

| 项 | 做法 |
|---|---|
| 纸面 | 暖白底 `#f5f2ea`、墨色字；暗色是同一套的暖黑版。变量仍在 `src/app/globals.css`，保持十六进制写法（`scripts/ui-check.mts` 读它算对比度） |
| 两支笔 | 松绿（`--color-accent`/`--color-primary`）：可点的东西、自己的学习安排；朱砂（`--color-now`）：“现在”这条线、待回答、过期未反馈。其余只有黑白灰 |
| 字 | 标题与大数字用衬线：拉丁 Newsreader（OFL，`src/app/fonts/` 本地加载，不发外部请求），中文落到系统宋体；正文仍是无衬线 |
| 层级 | 不用卡片套卡片：每一段上面一道线、一个衬线标题；数字排成一行，竖线分栏；理由/依据是左侧一道细线的旁注 |
| 外壳 | ≥1024px 左栏直接印在纸面上；以下是顶部一行刊头（刊标、今天/本周/方向、设置）。手机底部不再有标签栏 |
| Agent 栏 | 平时一行细条（52px）；聚焦、有内容或有提示时向上展开成便签，对话与结果在上、输入在下；点栏外或 Esc 收回；Ctrl+K 聚焦。待回答数量在细条右侧用朱砂标出 |
| 今天 | 刊头（日期大标题 + 一句话 + 四个数字）→ 桌面：时间线与“下一步/待处理/计时/最近变化”两栏；手机：下一步排在时间线前 |
| 本周 | 刊头 + 作息与规则 + 七天并排（桌面）或日期条 + 当天（手机） |
| 方向 | 主方向作刊头；四年阶段做成四栏年表；工作样本和阶段内容拆成“小标签 + 内容”的条目，不再是成段小字 |
| 时间线 | 课程 = 墨线；固定活动 = 双线 + 淡斜纹；待核对 = 虚线框；学习安排 = 松绿；空档 = 留白点线；“现在” = 朱砂线并写出钟点。手机上刻度拉长（1.35px/分钟），块的触摸高度不小于 40px |
| 其余页面 | 设置、收件箱、探索、复盘、通知、计划、项目、登录/初始化：页头、分段、数字条、徽标、按钮、提示、表单统一到同一套（`dash.module.css`、`explore.module.css`、`auth.module.css`） |

行为上只有两处变化，其余都是版式与样式：Agent 栏的收起/展开；提交失败时不再残留上一条的“已收到”。数据、接口、操作没有改。

## 已知的不足

- 中文标题用系统宋体：macOS/iOS 是宋体-简，Windows 会落到中易宋体（小字号偏细），部分安卓没有衬线中文字体时回落到无衬线。没有内嵌中文字体（体积过大）。
- 点开时间线上的一块，详情仍插在刊头下面把内容往下推；没有改成侧边或浮层。
- 旧计划页的“查看哪一周”等表单只换了样式，没有重排结构。
- 截图用的是示例数据；真实课表密度下七天并排的可读性没有验证。

## 上线后的修正：本周课表网格

主人上线后指出本周课表“线和格子很乱”。原因是七天各自画自己的线：横线到列边就断，列分隔线旁边又多一条空档的点线，表头每列一条下划线，“空档”文字还压在横线上；有备注的那天整列会往下错位。

改成一张表：

- 左边单独一栏钟点，横线由整张表统一画，整行贯通。
- 竖线只留列与列之间的一条；空档不再画任何线，只在中间留一行小字，悬停或聚焦时才圈出来。
- 表头是一行，七天等高，下面一条线；每天的备注放进表头，时间线不会再错位。
- 今天这一列铺一层很淡的底色，不另画线。
- 已过去还没反馈的学习块从朱砂虚线改成朱砂实线加淡底。

本地 464 项测试、144 项界面检查通过；桌面 1440、1100 和暗色看过截图。**这次修正还没有部署。**
