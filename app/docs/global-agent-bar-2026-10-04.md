# 全局 Agent 栏与指令入口

2026-10-04。所有工作台页面共用根布局中的一个输入栏；卡片、问题选项和“说一句”入口都定位到它。登录和初始化页不显示。切换页面保留本次浏览会话中的草稿、附件和对象上下文，刷新不保留未提交草稿；已提交记录仍从服务端读取。

## 用法与契约

- 直接写自然语言，原有材料识别、澄清和业务操作保持可用。
- 点击卡片，输入栏预填 `/指令`，同时单独发送对象 ID 或空档日期/起止时间。例如学习准入用 `/学习`，修改时间用 `/调整`，空档用 `/安排`，项目进展用 `/记录`。
- 点“待回答”的选项会预填 `/回答 内容` 和问题 ID/版本，用户仍可修改再发送。问题卡不再各自显示回答框。
- `/ 指令` 按钮或输入 `/` 打开列表，选择指令保留文字和附件。支持处理、安排、调整、学习、待办、决策、通知、活动、记录、回答、规则、复盘、探索、导入、撤销。
- 普通“说一句”只聚焦；卡片替换输入时暂存前一个草稿，可恢复。Ctrl/Cmd+K 聚焦，Ctrl/Cmd+Enter 提交。

共享定义在 `src/domain/agent-input.ts`；前端和 `POST /api/v2/intakes` 使用同一校验。只有开头的独立 `/指令` 作为模式，原始文字保留在投递与审计记录中。服务端解析正文并走既有 typed 操作、冲突检查及撤销流程，不把前缀交给模型猜。

分类指令用于已有事项，单独分类不编造活动时间；`/安排` 需要空档上下文；`/导入` 将正文作为材料，避免把材料内的命令句当成主人修改规则。`/记录` 用用户报告的分钟数，关联卡片项目，不把未来计划当成已完成实践。未知指令、错误参数和过期问题不能降级成新任务。修改失败后文字保留，修正内容会使用新幂等键，同一内容网络重试沿用旧键。
