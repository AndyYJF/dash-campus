# AI资讯：功能、接手地图与验证记录

日期：2026-10-09。状态：本地实现与隔离验收完成，尚未提交、推送或部署。本页不改变 [STATUS](STATUS.md) 中的生产版本。旧 Todo 数据、配置、服务和同步任务没有改动。

## 用户怎么用

打开主导航的 **AI资讯**（`/news`），看最近的模型、Agent、科研与应用变化。每条分开显示“发生了什么”和“Agent解读”，来源展开后能看到原链接、发布日期、摘录与资料类型。

- 第一次可点“更新资讯”，结果在后台生成。页面保留上次成功盘点，进行中会自动刷新。
- 默认每天按实例时区 **08:00** 盘点最近 **7×24小时**。新闻自动更新开关、全局定期AI总开关和每日模型额度都要允许；需要运行中的 worker。
- 点分类筛选，只看某类。没有收录某类就说明缺少资料，不凑数量。
- “问Agent：我能怎么学”把当前新闻标题和来源放进统一对话草稿，提交前可编辑；点击本身不调模型、不添加任务。
- “让Agent调整”用于自然语言调整更新规则。例如：“以后每天晚上九点更新AI资讯，只看最近三天”。已有资讯查看用只读工具，明确要求更新才启动新工作流。
- “停止本次更新”只停当前这次，之前的盘点保留；“暂停自动更新”影响以后的定期更新。已发出的模型请求可能已产生费用，停止不能撤回已消耗额度。

自然语言示例：

> 更新一下最近七天的AI资讯。
>
> 已保存的Agent资讯里有哪些值得我进一步了解？
>
> 这条新闻要看懂，需要哪些基础？先解释，别给我加任务。
>
> 以后每天晚上九点盘点最近三天。
>
> 停止这次资讯更新。

## 来源与诚实边界

固定公开订阅：

| 来源 | 官方订阅 |
|---|---|
| OpenAI | https://openai.com/news/rss.xml |
| Google AI | https://blog.google/innovation-and-ai/technology/ai/rss/ |
| Hugging Face | https://huggingface.co/blog/feed.xml |
| arXiv cs.AI | https://rss.arxiv.org/rss/cs.AI |

已有 Tavily 配置时，用两组 `topic=news`、`days=选定范围` 的有界查询补充检索。没有搜索 key 时仍可使用公开订阅；页面说明覆盖范围。参数依据 [Tavily官方接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)。本轮没有验证真实 Tavily API 调用，参数传递与计量在隔离测试中覆盖。

只使用订阅摘要和搜索摘要，不宣称读取了全部文章。发布日期来自源数据，模型不能填写日期或链接。日期缺失/无效的资料不进入近期盘点，并记录缺少日期的数量；过旧和未来日期排除。按规范URL去重，单来源最多12份，最终最多48份输入资料，模型最多生成12条报道，要求同一事件合并。

模型只能引用本次资料ID和能定位的原文摘录；无效ID、无法匹配的摘录或重复来源组合会使本次总结失败，不能发布。程序核对的是**引用存在**，不能证明模型每句改写都被原文支持，更不能独立核实厂商宣传的性能。正文按 React 文本渲染，不执行网页HTML或资料中的指令。厂商跑分与效果应注明是其宣称。

抓取不是全网监控。模型有资料才总结；部分来源失败展示覆盖说明，全部订阅失败且没有可用检索资料时不假装“无新闻”。失败/取消不覆盖上次成功盘点。成功抓取但近期资料为空时保存明确的空结果。

## Agent与HTTP契约

页面写入都用 `POST /api/v2/actions`，要求会话、CSRF与幂等键，复用现有事务执行器；没有新增旁路写接口。

| 注册操作 | 参数 | 自然语言意图 | 核验 |
|---|---|---|---|
| `request_ai_news` | `days=7`，1–30 | `ai_news` | 跟踪`ai_news_run`与job；排队/进行中不是已完成 |
| `cancel_ai_news` | 无 | `stop_ai_news` | 跟踪`ai_news_cancellation`与job；要求停止不等于已结束 |
| `update_ai_news_policy` | 可选`enabled/localTime/days/expectedVersion` | `ai_news_policy` | setting journal读回；确认依赖`ai_news_policy`事实版本 |

三个写操作均需要明确主人授权；资料或模型推断不自行更新规则。更新/停止不可撤回外部调用；政策可按 journal 撤销。新操作无排程、邮件或通知副作用。

只读工具 `get_ai_news({query?,category?,cursor?})`：默认给已有盘点标题与设置，用query/category读取对应事实、解读和引用。返回 observationId，封顶4000字符，长文本按nextCursor翻页；翻页保留筛选参数，ID来自已读结果。读取不联网、不调模型、不新建任务。页面GET也仅查已有数据。

## 预算、恢复与故障

- 模型使用`meteredModel`，搜索使用`meteredSearch`，实际请求计入现有日账目。来源订阅没有付费搜索调用。单次工作流最多180秒，模型调用超时45秒、续租15秒。
- 模型协议自身有限结构修复也计费；没有额外不受限自动重试。异常重领最多两次处理，已提交盘点直接认领，不再次生成。恢复可复用已经存下的来源。
- 同时点更新共享同一未完成run，范围不同会明确提示等待；HTTP同幂等键重放，相同键不同正文409。发布事务再次检查租约、取消、恢复暂停与定期设置版本。
- 定期总开关关闭/额度不足时推进当天调度标记，不积压补跑；之后手动更新仍需可用额度。恢复后取消旧更新，从后续日期继续，不补生成历史资讯。
- `full_json`包含资讯与非敏感政策，不含job_id和内部调度日期；数据库备份包含整个表。restore hold期间不抓取/总结，resume结束旧run并保留已有成功盘点。
