## 原问题记录（F01–F03 已于 2026-10-06 关闭）

### F01 / P1：新用户第一次选择阶段和去向失败

位置：`app/src/contracts/commands.ts:374`；`app/src/app/components/V2DirectionView.tsx:122`、`:152`；`app/src/workflows/snapshot.ts:385`。

未创建 `direction_profile` 时，快照返回 `version=0`。页面的去向按钮和“我现在在大一”按钮都会原样发送此版本；注册契约却要求 `expectedVersion >= 1`。因此首次点击在写入前就失败。

复现：新临时库 → 读取方向快照（profile.version 为 0）→ 执行页面同形参数：

```json
{"command":"update_direction_profile","expectedVersion":0,"confirmedStage":"year1"}
```

返回 `ok=false / VALIDATION`：`expectedVersion Too small: expected number to be >=1`。去向参数 `pathPreferences:["research"]` 同样失败。这不是模型理解问题，也不能靠重新说话消除页面缺陷。

建议：把不存在配置的版本契约正式定义为 0，允许此值并在事务内核对“尚不存在”；已有记录继续严格核对真实版本。不应为避错直接撤掉版本控制。增加真实 actions handler / 页面首次点击测试，以及 0 版本提交碰到另一请求已创建配置时返回冲突的测试。

### F02 / P1：新方向出现后续关联后，撤销创建抛出数据库异常

位置：`app/src/workflows/undo.ts:72`、`:104`；`app/src/workflows/ops/direction-workspace.ts:198`。

复现：创建一个工作样本对应的关注方向（批次 A）→ 单独关联现有项目（批次 B）→ 撤销 A。关联不会提升方向本体版本，撤销预检认为方向仍可撤；随后删除方向违反 `direction_project_links.track_id` 外键，抛出 `SqliteError: FOREIGN KEY constraint failed`，没有返回可理解的 `conflict`。

本轮在没有修改方向本体的独立临时库中确认了这一异常。事务回滚保护了数据，但用户无法正常理解和处理失败。

建议：撤销创建前检查本批次之外的入站引用，包括项目关联、阶段项、反思和资料线索；有后续使用则返回明确冲突，保留所有数据。不要用级联删除把后续主人记录一起清掉。覆盖 direction_track / roadmap_item 等新增可被引用实体，以及同批次创建并关联时按逆序可安全撤销的情况。

### F03 / P2：关注后工作样本的详细内容消失

位置：`app/src/workflows/snapshot.ts:417`；`app/src/app/components/V2DirectionView.tsx:182`、`:203`。

关注前，这张卡展示活动、试做、所需基础。关注后，快照将已关注模板从 `workSamples` 移除；“你在关注的工作”只渲染标题、状态、问题和关联项目，不展示后端已有的样本步骤、产出、基础和试做内容。暂停关注后也仍被排除，页面没有对应的恢复按钮。

结果：用户刚决定进一步了解，原本帮助其理解和开始的内容却消失。数据没丢，但这不符合“先理解实际工作，再试做”的用途。

建议：工作样本目录始终可读，卡片根据关注状态切换按钮；或让关注卡提供同样的详情展开、试做和恢复入口。采用其中一条一致实现，避免两套展示不断分叉。验证关注、暂停、恢复后都能查看相同步骤与基础。
