## 回退准备

保留旧镜像、旧源码及升级前数据库。回退应先停 web / worker，并备份当前数据，再以旧镜像运行恢复命令，使用 schema 11 的升级前备份。不能直接让旧镜像连接当前 schema 14 数据库。

恢复命令会保留当前数据库并进入外部动作暂停。核对数据后，确认旧实例均停止，再按 `deploy.md` 解除暂停并启动 worker；不自动补发可能已经发送的邮件。回退至升级前备份会失去升级后新增的业务记录，当前库备份用于保留与后续处理这些资料。

本轮没有创建 Git 提交或推送远端。上线使用的源内容可由服务器发布清单追溯；后续改动需重新打包发布，不能把当前分支名当作生产版本标识。
