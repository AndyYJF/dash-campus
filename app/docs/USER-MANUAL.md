## 1. 它能帮你做什么

Dash Campus 是你自己的学习与方向探索工作台。一个实例服务一个人，你和同学可以各自部署、各自保存数据。

日常最有用的是这几件事：

- 把课表、校历、通知、资料和自己的想法放进同一个入口，由系统判断怎么处理。
- 在课程、固定活动和休息之外，为真正需要投入的学习任务安排时间。
- 看清接下来做什么、为什么安排在这里，以及哪些事项还需要你决定。
- 留下做了什么、卡在哪里的记录，用这些事实调整后续安排和项目选择。
- 在配好邮件后，按你的规则发截止提醒或摘要。

它需要你提供真实情况。例如，想申请什么方向、晚上愿意学到几点、作业还剩多少。你不必一次把四年规划填完，可以先解决这周要做什么，再慢慢补。

目前主要通过网页使用。复杂图片识别、外部搜索和模糊指令理解取决于配置的服务，仍有边界；[第17节](#17-遇到问题怎么办)说明了常见处理办法。

## 2. 第一次使用：先让它知道你的基本情况

### 2.1 登录

如果实例已经初始化，打开网址，输入主人密码即可。这里没有给一群学生共用的账户列表。

新部署的实例会进入初始化页面。输入部署时设置的初始化口令，再设置至少8位的主人密码。完成后进入登录页。初始化口令由部署者提供，和日常登录密码分开使用。

### 2.2 先说身份和目标，分两次发就够了

在 Agent 输入栏里，可以先说：

> 我是人工智能专业大一本科生。

再说：

> 这学期主要目标是巩固数学和编程基础。

如果还有科研或继续深造的想法，可以补充背景；看看系统最后保存成了什么，而不是只看它回复得是否流畅。目标最好先选一个主方向，例如“数学和编程基础”，再保留一两个想试试的方向。

“对科研感兴趣”表示你的倾向，不表示你已经满足某个实验室、比赛或奖学金的条件。资格条件需要有具体依据。

### 2.3 放入课表，回答学期问题

把课表文字、图片或文件放进输入栏，点“发送”。系统可能会问学期第一周是哪一天，或现在是第几教学周。

按真实情况回答。例如：

> 现在是第5周。

这里的“第5周”只是示例，不要照抄。它会根据你回答当天的日期推算学期起点；如果你在导入旧学期资料，最好直接说明首周周一的日期。

导入后去“本周”检查一两门熟悉的课：星期、起止时间、单双周、教室是否对得上。如果整体错开了一周，应先纠正学期起点。

### 2.4 看一眼作息，改成你能坚持的样子

进入“本周”，找到“作息与规则”。首次显示的通常是暂定模板，用来先估算你能学多少。

模板会列出可安排时段、三餐、交通预留、每日学习上限和机动时间。你可以点“就按这个安排”，也可以点“一句话改…”或直接说：

> 晚上十点后不排，工作日最多两小时。

不用为了把图填满而把上限设得很高。课已经很满的日子，留出一点自主学习时间也完全合理。

### 2.5 先添加一件具体的学习任务

例如：

> 明天复习微积分极限部分，预计需要一小时。

具体到一个能开始的小动作，比“学好数学”更容易安排。提交后检查它是否是学习任务、估时是否正确，以及排在什么时间。

第一天完成这几步就可以开始用了。校历、资料、项目和邮件都可以之后补，不需要把所有设置一次填完。

## 3. 每天怎么用

### 开始一天时：看“今天”

主要看三件事：下一节课在哪里、下一段学习做什么、有没有必须先回答的问题。一般不用每天重新生成整份计划。

今天情况变了，就直接说明：

> 今晚不学，留给休息。

或者：

> 根据每天的课程重新安排时间。

第二句话已经足够让 Agent 开始判断。你没有说范围时，它默认处理未来七天，并在结果里说明范围。

### 开始做一件事时：从那段安排点“开始”

从学习块点“开始”，系统会尝试为这一段启动关联计时。也可以在“今天”的计时区写下正在做什么，再点“开始计时”。

### 做完或停下来时：留下一个短记录

不用写日记，一两句话就够：

> 今天复习极限40分钟，基本题做完了，分段函数的左右极限还会混淆。

如果用了计时，先结束计时，再写成果和卡点。不要把同一次40分钟又作为新的40分钟重复记入。

### 一周结束时：看“本周”和“回顾”

看看投入去了哪里、哪些工作一直往后拖、哪个项目值得继续。你可以说 `/复盘 本周`。复盘建议不会自动替你承诺一个新方向。

## 4. 认识五个主要页面

| 页面 | 什么时候打开 | 主要看什么 |
|---|---|---|
| 今天 | 开始一天、准备学习、刚做完事情 | 下一节课、今天时间线、下一步、待处理事项、计时与最近变化 |
| 本周 | 看整体负担、改作息、挪安排 | 桌面七天时间轴或手机单日时间线、每日容量、课程、学习块、冲突与未安排任务 |
| 方向 | 看清阶段、了解实际工作、选择探索项目 | 四年阶段、去向偏好、工作样本、关注方向、候选与试做项目 |
| AI资讯（已上线） | 了解近期变化、判断是否值得进一步学习 | 模型/Agent/科研/应用盘点、来源依据、学习解读与统一Agent追问 |
| 对话 | 想连续聊、回答问题、发材料或回看处理过程 | 你的消息和 Agent 回复按先后排列，输入框固定在底部 |

设置入口在页面的设置图标或侧栏里，主要放集成状态、邮件、AI用量和数据导出。

“方向”页面底部还有收件箱、回顾和探索记录入口。收件箱可以查看被折叠的通知；回顾里看已有周复盘；探索记录里看以前搜过什么、得到了什么。

`/plan` 等旧页面仍可能保留。日常看数据用“今天、本周、方向”，集中与 Agent 沟通用“对话”。

### AI资讯：知道最近发生了什么，决定值不值得进一步了解（已上线）

主导航新增“AI资讯”，综合盘点模型、Agent、科研与应用。打开先看新闻事实和“对学习/科研的意义”；展开来源能看到日期、原链接与摘录。点分类可只看某类，没有资料就不会凑数。

第一次点“更新资讯”。默认以后每天按实例时区08:00盘点最近7天；需要运行中的后台服务、全局定期AI开关和可用调用额度。点“暂停自动更新”停止以后的定期盘点；“停止本次更新”只停正在进行的这次。更新失败会保留上一次成功的盘点。

点新闻下方“问Agent：我能怎么学”，标题和来源会进入同一个对话输入框，你可以改完再发。点击本身不会自动加任务。也可直接说：“以后每天晚上九点盘点最近三天”“先解释这条新闻需要哪些基础，不要给我加任务”。

已有资讯查询只读，明确要求更新才联网抓取。没有搜索服务时用官方公开订阅；日期不明确的资料不当作近期新闻，页面说明覆盖缺口。Agent的解读是分析建议，不能把引用存在当作每句话都已独立核实。更详细的范围见[AI资讯说明](ai-news-2026-10-09.md)。

## 5. 统一 Agent 输入栏怎么用

### 5.1 找到输入栏

导航里的“对话”会打开完整聊天页：你的消息在右侧，Agent 回复在左侧，从上到下读。往上翻可以查看旧消息，再点“查看更早的消息”继续加载。

工作台页面底部也有同一个输入栏，点击后展开聊天。可以点“说一句”聚焦输入框，或点“打开对话页”进入完整页面。浮层只在你点“收起”或按 Esc 时收起，点击页面空白不会突然关掉对话。

你可以直接打字、粘贴课表、贴链接，或者点“添加图片/文件”。粘贴剪贴板中的图片也可以加入附件。

点“发送”提交。电脑上按 `Enter` 发送、`Shift + Enter` 换行；`Ctrl + Enter` 或 Mac 上 `Command + Enter` 也能发送。手机键盘回车用于换行，点“发送”提交。输入法选字时的回车不会发送。`Ctrl / Command + K` 可以快速聚焦输入栏。

Agent 处理时会显示“正在处理”，需要你补充的信息直接出现在对话里。点击问题选项会把回答填进输入框，你可以修改后再发送。回复里的“处理依据与核对”默认收起，想看它依据了什么、实际改动是否核对通过时再展开。

### 5.2 自然语言和 `/指令` 都能用

下面两句都可以：

> 根据每天的课程重新安排时间。

> /调整 根据每天的课程重新安排时间。

`/指令` 用来说明你大致想做什么，不要求你记住一套参数。点输入栏里的“/指令”可以选，不必背下来。

如果只是想看数据，可以说：

> 看一下目前每天的时间安排。

这种请求只会读取现有安排，不会建立一个叫“查看时间安排”的任务。

### 5.3 从卡片发起，系统才知道“这个”是谁

点学习块上的“挪到…”、待处理事项上的“告诉 Agent 怎么处理”，或问题上的回答选项，输入栏会自动带上相关对象或问题。

你会看到“关于：……”或“回答：……”提示。例如，你刚点了某一段学习安排，就可以接着说“把这段挪到明天下午”，不用重新输入完整标题。

提示旁边的“×”可以取消这次上下文。想换一个话题时，先检查有没有还在回答旧问题。带着问题上下文时，新的文字会被当成那个问题的回答。

如果旧问题已经回答或作废，系统会拒绝旧卡片的回答，请查看最新问题再答。后续本地修复还会在你直接答清某个业务问题后，收起与它有关的旧“你在回答哪个？”；这项补充尚未上线，状态见[当前状态](./STATUS.md)。它不会把之前未指明对象的“可以”自动套给其他事情。

点卡片只是把内容带进输入栏，带省略号或跳到输入栏的动作通常还要你补完、发送。也有直接生效的按钮，例如“锁定”“这次停课”；点之前看清按钮含义。

### 5.4 草稿和已提交记录怎么保存

在工作台内部切换页面，未发送的文字和附件会跟着输入栏保留。如果点卡片替换了草稿，可以通过“恢复草稿”找回之前保留的那一份。

目前未发送草稿没有离线保存保证，刷新或关闭页面可能丢失。长内容建议先写在自己的笔记里，再粘贴过来。

已经提交的内容有服务端历史记录，刷新后会重新读取。打开“对话”或展开工作台聊天即可查看消息、结果、问题和变化；往上读旧消息时，新一轮刷新不会把你强行拉到底部。卡片问题答完后，续办结果会接在回答后面。

## 6. 导入课表、校历和其他材料

### 6.1 统一从输入栏投递

课表、校历、通知和资料都可以从同一个入口发。系统会先判断材料类型，再决定提取哪些信息。

可以直接放材料，也可以加一句说明：

> /导入 这是这学期的课表，请按它更新课程安排。

接着附上文件或图片。说明和材料一起发送，比分开几次只发“导入一下”“这个”更容易理解。

### 6.2 当前能接收哪些格式

| 材料 | 建议怎么发 | 需要留意什么 |
|---|---|---|
| 课表文字、SDCT1 | 直接粘贴或TXT文件 | 原有SDCT1可直接用，仍需要正确学期起点 |
| 课表/校历图片 | 清晰截图或原图 | 需要图片识别能力；复杂布局可能读错，导入后检查 |
| TXT、Markdown | 附件或直接粘贴 | 适合通知、说明和个人记录 |
| CSV、XLSX | 附件 | 读取表格单元格；不会执行宏或替你在Excel里重算公式 |
| PDF | 附件 | 有文字层时优先读文字；扫描页需图片识别，复杂扫描件仍可能失败 |
| ICS日历文件 | 附件 | 主要支持可识别的一次性事件；不支持的重复、全天或跨夜事件会说明原因 |
| 网页链接 | 贴公开链接 | 可能被登录、反爬或动态网页挡住；读不到时可改贴正文或图片 |

一次最多10个文件；单个不超过10MiB，合计不超过30MiB。文字最多100,000个字符，一次最多2个链接。PDF当前只处理前30页，超出的部分不会当作已经读过。

旧 `.xls` 请先另存为 `.xlsx` 或 `.csv`。其他未支持的格式，可以复制可见文字，或转成清晰图片。文件接收成功之后还要看提取、导入结果，不能只看附件名字已经出现。

### 6.3 课表导入后检查这些地方

按下面顺序看，比逐条检查整学期省事：

1. 当前教学周对不对。
2. 今天或明天一两门熟悉的课对不对。
3. 有单双周、离散周次、只有一次的课程，再抽查对应日期。
4. 本周课程占用是否符合你的直觉。

如果导入的是旧截图，不要只回答“现在第几周”，应直接提供那个学期第一周周一的日期。

同一份课表重复投递不会因此多出一套相同课程。不过课表有变化时仍要检查结果，不要把任意不同截图都当作一定能自动识别为同一版本。

### 6.4 校历、国家假日和学校补课是不同信息

校历说明学期、教学周、考试或放假安排。国家节假日说明公历上的放假和调休。学校是否补课、补哪一天的课，需要学校的依据。

可以把学校官方校历图片、PDF或公开网页放进输入栏。系统读不清或和现有学期起点冲突时，会问具体问题。

国家调休上班日不会一律变成上课日。如果页面写“教学安排待核对”，表示学校补课情况还没有确认。拿到学校通知后补充材料，或者点相应日期的卡片说明补哪天的课。

可用官方来源核对节假日；也可以表达希望定期更新校历，例如“每7天自动更新校历”。实际更新受来源、网络和配置影响。看到“未获取”或“待核对”，按未知处理，不要理解成没有假日或不用上课。

## 7. 时间安排是怎么算出来的

### 7.1 页面里的数字代表什么

| 显示 | 用人话说 |
|---|---|
| 课程占用 | 这一天实际展开出来的课程用了多少时间 |
| 学习预算/每日上限 | 你愿意给自主学习留多少，不包含“把所有空闲都用上”的要求 |
| 已记录的实际学习 | 你报告或确认计时得到的投入 |
| 按计划暂扣 | 某段安排已经结束或完成，但还没有确定实际用时，先按计划保留这份占用 |
| 已安排的未来学习 | 后面已经承诺给具体学习块的时间 |
| 还能新排的学习 | 在作息、课程、实际投入和既有安排之后，还能增加多少学习投入 |
| 暂定 | 数字依赖尚未确认的作息等假设 |

“今天还能新排0分钟”不一定表示你一整天没有空。可能是学习预算已经用完，也可能是剩下的学习时间已经给了现有安排。

### 7.2 它会怎样找到位置

系统先按课表和校历确定课程，再扣除固定活动、三餐、交通和不可学习的时间。之后结合每日学习上限、已经投入的时间、现有学习块和机动比例，计算还有多少容量。

只有适合安排成学习块的事项才会进入排程。系统还会考虑任务剩余需求、截止、优先级、已有目标关联、时段偏好和当天课程负担。

所以课多的日子通常不适合再塞大量自主学习。输入“课多的日子轻松一点”时，Agent可以结合实际课程量提出临时每日上限，再交给排程器算具体位置。

### 7.3 不知道工作量时怎么办

学习任务工作量未知时，系统可能先安排一段25分钟左右的起步工作，让你取得一点可以反馈的进展。它不代表整个任务只需要25分钟。

做过以后，可以补充：

> 复习极限还剩大概一小时。

投入了一小时还没完成，也不会自动证明完成了一半。对于“完成报告”“复现实验”这类看成果的任务，说清还剩什么更有帮助。

### 7.4 稳定比每天换一张图更有用

普通自动调整会尽量保留合理旧安排。手动放在某个位置的块、锁定块和已开始的块会受到保护；近期安排也有保护规则。

你明确要求某几天重新安排时，会放开该范围内未锁定、未开始的自动学习块，让系统重新计算。它仍不能占用课程，也不会把所有已有块都随意挪走。

你说的那一天恰好是某件事的截止日时（例如“概率论大作业明天就要交了，帮我优先安排”），系统分不清你是想从今天起排到截止前，还是只动那一天，会先问你：“从今天到截止前都可以排 / 只调整那一天 / 先不要，什么都不改”。回答前不改任何安排。

如果新课和锁定块冲突，系统会标出来请你选择。锁定表示“尽量保留我指定的位置”，不表示冲突已经解决。

## 8. 用自然语言改安排

### 8.1 不必先想好精确钟点

这些表达都可以作为时间调整的入口：

> 根据每天的课程重新安排时间。

> /调整 学习安排优化一下，课多的日子轻松些。

> /调整 下周按课表重新安排学习时间。

默认是未来七天；“本周/这周”指本周一到周日，“下周”指下一周一到周日。过去的时间不会重新分配。

比如周日说“这周”，本周只剩周日了。想处理之后的七天，就说“未来七天”；想处理下一个完整周，就说“下周”。

如果主要是两个方向抢时间，Agent可能问你优先哪个。直接回答自己的取舍即可，不需要回到设置页填一堆字段。

### 8.2 只挪一个块，最好先点那个块

从时间线点一段学习安排，再点“挪到…”，把句子补完：

> 把这段挪到明天下午。

它会带上这一段的对象信息。没有点卡片时，最好写清名称，例如“把明晚的微积分复习挪到周六”。若有几段都对得上，系统会问你是哪一段。

空档也可以点。点“在这里安排…”后，输入想做的事；也可以直接写“/安排 明天下午3点到4点写微积分作业，4点到5点写英语作业”，不用先点空档。话里没写时间时才需要点空档。每件事照自己说的时间排，撞课或已经过去会说明原因，不偷偷挪到别处。

一次最多处理六件，后面的内容会明确提示你再发一次，不会悄悄丢掉。换日期后不会沿用上一天下午；没有“上午/下午”前缀的 `08:00` 就是早上八点。跨夜请拆成两天来安排，`24:00` 只用于当日结束。拿不准怎么安排时，可以直接用自然语言，让 Agent 先读现状、给建议或向你提问。

### 8.3 一次调整和长期规则分开说

只影响一次：

> 今晚不学。

长期习惯：

> 以后每周三最多学习一小时。

如果只说“周三最多一小时”，系统可能追问是这一次还是以后每周都这样。

对于“最近太累，你帮我决定”这类表达，Agent可以提出方案。如果方案会改变长期规则、停学时段、某个具体块或截止，它会先给你确认，而不是把推测直接变成事实。

停学时段有一个特殊点：明确执行“不学”规则时，其中尚未开始的手动或锁定块也可能被让出。模型提出这类建议时，确认提示会说明这个影响。

### 8.4 改完看结果，不只看回复

看清日期范围、规则到底改了什么，以及“学习安排已更新”还是“学习安排不需要变化”。

“已更新”有时表示重排授权或规则已保存，并不表示一定新增了学习块。安排本来就符合规则时，不移动也属于正常结果。

## 9. 任务、待办、通知和决策怎么区分

并不是所有写在清单里的东西都要占一段学习时间。

| 类别 | 例子 | 通常怎么处理 |
|---|---|---|
| 学习任务 | 复习极限、训练实验基线、写研究报告 | 根据需求和容量安排学习块 |
| 日常待办 | 买笔芯、买设备、绑定银行卡 | 保留在待处理区；有截止时按规则提醒，不自动占学习预算 |
| 决策事项 | 要不要参加比赛、要不要申请某项目 | 先决定是否投入，再拆出实际行动 |
| 通知 | 助学金申请公告、教授开放日通知 | 看资格、时间和下一步，不把通知标题直接当学习任务 |
| 活动 | 讲座、见面会、训练 | 有可靠起止时间才按活动处理；分类标签本身不会编造时间 |
| 待确认 | 只写了一个名字，看不出要做什么 | 补关键意思后再决定是否排学习时间 |

你可以从“今天”的待处理卡片点“告诉 Agent 怎么处理”。也可以按已有事项名纠正：

> /待办 买红笔芯

> /决策 OceanBase比赛报名

> /学习 复习微积分

这些分类指令针对**已有事项**。想新增任务，请直接说要做什么，或导入新材料；不是在 `/学习` 后随便写一句，就会创建新任务。

比赛报名先是一项选择。真的决定参加后，才进一步拆成看规则、找队友、做练习或完成提交等具体工作。

## 10. 学习时怎么计时和记录

### 10.1 计时

“今天”页面有计时区。填“复习极限”，点“开始计时”；停下来时点“停止并计入”。

从学习块点“开始”，会尝试关联这一段。已有另一段计时在跑时，不要再开一份来重复计算；检查计时区现在记录的是什么。

忘了停止、计时很长或跨日时，系统可能要求你确认实际分钟。可以填真实投入，也可以放弃这次计时。不要把离开电脑的整个晚上都算成学习。

### 10.2 完成一段和完成整项任务

“这一段完成”表示这次安排结束了。一个报告排了三段，完成第一段不等于整个报告写完。

整体做完时，应告诉系统具体任务已完成，例如：

> 极限练习做完了。

若只完成一部分，记录成果和剩余需求即可。

### 10.2.1 过去了还没记录的一段

一段学习安排的时间过去了、你还没点完成或跳过，时间轴上它会标“待反馈”，Agent 栏里会出现一个问题：“这段做了吗，还剩多少？”。在你回答前，系统不会把它当成做完，也不会再为它整段补排一次。

可以点选项，也可以直接说：

> 做了40分钟，还剩30分钟。

> 这段做完了，作业还没写完。

> 没做，忘了。

系统按你说的记录：做完了就记完成；没做就保留这段记录并另排一次；做了一部分就记下实际分钟，只排剩下的。只说“做完了”而这件事还有别的安排时，只算这一段完成。同一件事有几段都过去了，会一段一段问。

“完成了一半”说的是进度，不代表实际学了计划时长的一半。只这样回答时，系统会接着问大概做了多久、还剩多少，不凭空记分钟数。你也可以只说“完成了一半，还剩30分钟”：系统更新剩余安排，不会虚构实际用时。同一天同一任务有几段，各段的反馈分开计算；一段填了实际时间，不会让另一段的完成反馈被忽略。

回答落实后，今天、本周和计划页会自动重新读取安排。“待反馈”会随真实结果更新；已经撤回的安排不能继续修改，不需要再删除一次。

### 10.3 用一句话留下有用的实践记录

可以用 `/记录`，例如：

> /记录 今天复习极限40分钟，完成10道基础题，分段函数题还容易漏看左右极限。

从项目卡片发起记录更容易关联到那个项目。没有合适对象或匹配不唯一时，系统会问应该记到哪里。

记录建议包含：做了什么、多久（知道就写）、留下什么成果、哪里卡住。没有准确用时就不要硬凑分钟数；这比把计划时长冒充实际投入更有用。

`/记录` 用来写已发生的实践。明天要做的事，请直接表达计划，别把它写成已经做过。

### 10.4 避免同一次投入记两遍

计时和手动记录都可能涉及同一段投入。如果系统提示把两次记录算成同一次，核对一下；确实是两次独立工作，可以选择分开。

用了计时后补记成果时，可以只写成果和卡点。发现某次实际分钟不对，也可以纠正，例如“刚才那次其实用了40分钟”。

## 11. 探索方向与选择项目

### 11.1 先看阶段和工作样本

打开“方向”页可以看到四年通用阶段（大一到大四）和几类工作平时做什么。这是示例说明，不是学校培养方案，也不会据此说你落后。

如果你明确自己处于哪一阶段、更偏向科研还是就业，可以说出来或点页面上的选择；两者可以同时保留。系统不会因此生成一整年待办，也不会估算录取概率。

入学年不知道也能用。第一次点“大一”或去向选项就能保存，不需要先填完资料。

工作样本会列出实际步骤、可能留下的作品和需要的基础。点“继续了解”是保存关注，不会自动建任务或占学习时间；“先不看了”暂停这份关注，已有项目和记录保留。暂停后仍能阅读完整样本，也可以恢复关注。

### 11.2 先给项目条件

在“方向”看主目标和已有项目。想找新的小项目，可以说：

> /探索 想找一个适合AI大一、能用普通电脑完成的机器学习小项目，最好能留下实验报告。

条件越具体，越容易筛选：目前会什么、每周能投入多少、希望得到作品还是理解一个问题。不要只写“给我一个厉害的科研项目”。

在线检索依赖搜索服务。只有模型、没有搜索，并不意味着系统已经找到并读过最新网页。看候选里的来源状态：“已读到原文”“只有摘要”“你提供的资料”所能证明的程度不同。

### 11.3 候选是建议，试做是你的小实验

选择前先看它要回答什么问题、第一步是什么、需要哪些能力、哪些条件还没确认。

你可以从候选卡片发起试做，或明确选择已有候选。当前代码的卡片操作默认选择两周窗口，只建立第一步；这不表示两周每天都占满。想改投入条件可以在统一栏说明，最终以实际结果卡中的期限和安排为准。选择前的共享预算投入预览仍在后续计划里，暂时不能把页面建议当成已预留时间。

有多个候选、名称容易混淆时，从卡片发起更稳妥。试做会在工作台里建立有期限的小项目，不会替你报名比赛、联系导师或作出外部承诺。

### 11.4 用成果决定是否继续

一两周后看实践证据：有没有完成第一步、有没有能展示的成果、是被环境问题卡住还是对问题本身不感兴趣。

在项目卡片记录进展，查看未解决问题、下一步和资料。暂时不想做可以明确暂停；想正式投入，再表达这个决定。当前“转为正式投入”主要改变项目状态，还没有接好自动续建后续步骤：需要在结果里确认下一步任务和学习安排确实出现，不能只凭标签判断已经续排。

项目没有记录时，系统无法可靠判断你取得了多少进展。每天留一两句话，通常比增加一页长期愿望更有帮助。

## 12. 身份筛选、通知和邮件

### 12.1 先让筛选有依据

提供真实身份后，系统才有依据判断某些通知是否与你有关。例如本科/研究生、专业、年级或校区。

可明确表达：

> 我是本科生，不用给我研究生专属通知。

原通知会保留。明显无关的通知可以折叠，仍能从收件箱找到；资格不明的通知可能问你一个关键条件。

“想科研”不能证明你符合科研项目要求，“不想看”也不等于那条通知没有截止或后续义务。看清筛选范围再确认。

### 12.2 通知不会凭空来到工作台

你可以手动粘贴通知、上传材料或贴链接。部署者也可以安装旧Todo/校园来源的只读桥接，把来源更新带进Dash。

没有配置来源时，工作台不会自动读取你的QQ群、微信或邮箱。已有桥接只读取旧来源，Dash里的调整不回写Todo。

### 12.3 邮件先配通，再决定发什么

服务器需要配置发信服务、发件人和唯一主人收件地址。设置页显示是否配置，也能预览模板、发测试邮件。

先发测试邮件，去收件箱或垃圾邮件确认真的收到。然后再开启截止提醒、每日摘要或每周回顾。

可用自然语言表达，例如：

> 开启提醒。

> 每天晚上九点半发日报。

> 关闭日报。

摘要默认不开启，开启之后才会按规则运行。模板可以调主题前缀、显示栏目和隐私选项；先预览版式，满意后再保存或测试。

“服务器已接受”表示发信服务器接下了邮件，是否到达还要看收件箱。投递结果“不确定”时，系统不会偷偷自动再发一份；手动重发前留意可能重复。

## 13. 每周复盘

可以说：

> /复盘 本周

或者进入“方向”底部的“回顾”。`/复盘` 不写范围时默认上周。

复盘优先汇总你已经记录的事实：完成什么、花了多少时间、卡在哪里、哪些工作一直没有推进。AI再据此给观察和建议。

你可以重点问自己：

1. 最重要的目标有没有实际投入？
2. 没完成的事，是时间不够、工作量估少了，还是根本不想做？
3. 下周要减掉什么、继续什么、先验证什么？

建议和已经执行的修改分开看。看到“建议减少项目投入”，不表示项目已经被暂停。认可后明确告诉 Agent 怎么改。

记录不足时，复盘会缺少依据。不要因为没有生成漂亮总结，就补写虚构的投入。

## 14. 看懂 Agent 的结果与问题

| 状态或提示 | 意味着什么 | 接下来做什么 |
|---|---|---|
| 已收到/正在整理 | 内容已提交，还在处理 | 等待结果；可以在历史里查看 |
| 已回答 | 读取了现有数据并回复 | 看内容或点导航链接；不会有需要撤销的业务修改 |
| 需要你回答 | 缺少关键事实或取舍；也包括“已执行，但截止前排不下/锁定块撞课，需要你选怎么取舍” | 点问题/选项，或在统一栏用自己的话回答 |
| 已更新 | 有事项或规则保存成功，执行后读回核对一致 | 再看变化列表和排程后续，确认实际效果 |
| 无需变化/学习安排不需要变化 | 已检查或计算，当前不需要改 | 不必为了出现新块而重复提交 |
| 部分完成 | 一份投递中有些内容成功，有些未完成；或执行后核对发现没达成（摘要里写“核对未通过：…”） | 看失败或待回答的具体部分；已完成的部分保留 |
| 受阻：自动修正后仍未达成，已停下 | 系统在原范围内自动修正过（最多两次），同样的问题还在，就停下不再反复尝试 | 按摘要里的冲突或问题做决定；不会自己扩大范围或改截止/课程/预算 |
| 没有办成 | 当前操作没有完成 | 看原因，按缺口补充或纠错 |

结果卡下方的一行核对文字说明执行后的检查结论，例如“已核对：结果与要求一致”“只查看，没有改动任何东西”“已在原范围内自动修正 1 次”。邮件只核对已经交给发送服务，不核对是否送达，也不会自动重发。

一份材料可能拆成几件事。课表已导入、其中某个日期还待核对，都要分别看；不是必须全部成功或全部失败。

问题通常说明为什么需要问。你可以选答案，也可以用自己的话回答。最好从那条问题发起，避免回答挂到别的问题上。

回答期间相关对象改变、问题已经失效时，系统可能拒绝旧答案。回到当前问题或卡片重新处理即可。

### 14.1 直接在输入栏回答、改口、停下

- **用自己的话回答**：有问题在等时，直接说“第一个”“可以”或选项原文，也可以说“那就先顾数学吧”。只有一个问题在等时直接算作回答；有几个问题同时在等、又说不清是哪一个时，系统会先问你指的是哪一个。问别的事（例如“明天有什么课”）不会被当成回答。
- **回答“你指的是哪一个”**：接着说“第二个”或定位卡上的选项即可，也可以选“作为新的要求”。直接把业务问题答清楚后，旧定位卡会收起，孤立的旧“可以”不会套到别的问题上。若另一设备已答过或作废目标问题，会明确拒绝旧回答。
- **结果出来后改口**：接着说“改成下周吧”“周末别动”，会在同一件事上出新的一版：旧一版还没执行的部分、待答问题和待确认方案作废，已经生效的修改不会自动撤回（需要的话点撤销）。
- **带条件地答应**：确认时可以直接说“可以，但只改工作日，周末别动”“好，不过刚才那门课别挪”。只有单纯的“可以”“先不要”会被当成同意或拒绝；带条件、带疑问（“可以吗？我还没想好”）的回答会按整句出一版新方案再问你，旧方案不执行。如果你的条件没有让方案有任何变化，系统会照实告诉你“和上一版完全一样”，多半是它理解错了你指的对象，请直接说不改哪一个。
- **说过的条件会一直守着**：“周末别动”“别碰我放假那几天”“这门课别挪”会记在这件事上，之后改口（“改成下周”“再少一点”）、换设备或隔几小时继续都仍然有效，结果卡的目标信息里能看到“你说‘周末别动’”。同一段对话里接着说别的事，这类“别动”也会沿用，显示为“沿用你前面说的……”；如果你这次明确要动那部分（比如“周六晚上加一小时英语”），系统会先问你，确认后只这一次照做。要取消某个条件，直接说“周末可以排了”。
- **确认写的是实际修改**：确认里会列出要改的对象和前后变化，例如“挪动学习块：「高数复习」10-18 15:00 → 10-18 19:00”“工作日结束时间：22:00 → 21:00（长期）”，并注明不能撤销或会发邮件的步骤。等你确认期间相关作息或安排被改了，旧确认作废，系统会说明变了什么再问一次。
- **停下**：单独说“先别做了”“停一下”“取消吧”，会立刻停掉当前这件事还没执行的部分，并列出哪些已经生效。
- **继续这个目标**：回复里的“继续这个目标”，或对话里的「继续以前的目标」列表，都可以在刷新、换设备或隔几个小时后接着说。列表来自服务端，不依赖本机草稿。若这件事已经被改成新的一版，系统会提示你看最新的那一版，不会按旧版本执行。
- **理解错了**：结果卡上可以标“意思理解错了/对象找错了/应该先问我/不该问”。这只用于以后改进理解，不会改动你的数据。

### 14.2 试用指标

设置页的“试用指标（近 7 天）”汇总你在统一栏的投递：多少由模型理解、多少次问过你、核对通过/部分完成/受阻各多少、自动修正了几次、标了几次“理解错了”，以及每天的模型请求数和响应时间。它只读取已有记录，不调模型、不改数据；样本很少时比例仅供参考，没有标“理解错了”不等于没有误解。

卡片上还有一行“各环节”：理解失败、问过你、等你确认、因超出范围或违反你说的条件被拦下、确认期间情况变了重问、执行失败、后台还在进行、核对通过、部分完成、自动修正、你改口重来各多少次。“模型耗时”只算等模型回复的时间；“主动执行时间”是 Dash 实际处理一份投递的时间，含等模型、查数据、执行与核对，不含排队和等你回答。单份投递累计 180 秒的上限按主动执行时间计，用完就停下并说明，已经做完的保留。

## 15. 撤销和纠错

### 15.1 刚才改错了

在结果卡或“最近变化”里点“撤销”。也可以输入：

> /撤销

它针对当前对话中最近可撤销的变化。只读查询没有业务变化，因此没有撤销按钮。

### 15.2 为什么会出现“撤销冲突”

比如Agent先把任务改成学习任务，你后来又修改了这项任务。此时撤销最初的修改可能覆盖你的后续操作，所以系统会阻止。

先看任务现在的状态，再明确说希望改成什么。可以从当前卡片发起纠正，而不是不断重复点旧撤销。

### 15.3 旧表单修改可能没有统一撤销

部分旧版表单还没有接入同一份变更记录。重要修改尽量从统一Agent栏或当前卡片操作；找不到撤销入口时，用同一对象的当前编辑入口纠正。

撤销也不能收回已经送出的邮件。先停掉后续提醒或摘要，再核对已发送记录。

## 16. 常用指令速查

不需要把它们背下来。点“/指令”即可选择；不写前缀，普通自然语言仍可使用。

| 指令 | 适合做什么 | 示例/注意 |
|---|---|---|
| `/查看` | 读取现有数据 | `/查看 本周时间安排`；不写内容默认看今天安排 |
| `/处理` | 说明想怎样处理一个事项 | 从事项卡片发起后写具体意图 |
| `/安排` | 在选中的空档安排工作 | **先点空档**，再写 `/安排 整理数学错题` |
| `/调整` | 改已有安排，或让Agent决定怎么重排 | `/调整 根据每天的课程重新安排时间` |
| `/规则` | 修改学习时段或时间政策 | `/规则 晚上十点后不排学习` |
| `/学习` | 把已有事项纳入学习排程 | `/学习 复习微积分` |
| `/待办` | 把已有事项保留为日常待办 | `/待办 买红笔芯` |
| `/决策` | 把已有事项标为待决定 | `/决策 比赛报名` |
| `/通知` | 把已有事项标为通知 | 后面写已有事项名，或先点它的卡片 |

指令后面先空一格再写正文。输入栏提示“不认识指令”时，可从菜单选，或去掉前缀直接表达意思。

## 17. 遇到问题怎么办

### 一直“正在整理”，没有结果

先在历史里看是否已经有待回答问题。没有问题且长时间不结束，可能是服务器后台处理服务没有运行、模型请求超时或任务失败。让部署者检查worker和集成状态，不必连续发十遍同一份材料。

### 显示模型未配置或调用预算用完

“模型未配置”需要部署者填写服务端配置。密钥不要粘到Agent输入栏。

预算用完时，模型相关理解和生成会受限。基础页面、已有数据查看和部分明确操作仍可用；可在设置看AI用量，决定等待下一周期或调整额度。

### 上传了图片，但没正确读出课表

检查图片是否清晰、有完整周次和时间表。很长的图可以按完整区域拆成少量清晰图片；不要切掉标题、星期或节次说明。

失败时可先复制文字，或用已有SDCT1。复杂课表截图、扫描PDF仍需要逐项核对，不要把“原件已保留”当成“课程已导入”。

### 课表日期错了，课程占用也不对

先核对学期起点、教学周、单双周与学校调课。一个学期起点错了，会影响很多门课；不要先逐门课手动挪一遍。

### 任务“排不下”

看具体原因：空档不够、超过每日预算、截止太近、还有受保护安排，或任务做过一段后需要你补剩余需求。

可以报告剩余工作、暂停次要任务，或说明新的取舍。通知、购物待办和比赛选择如果被误当作学习任务，先改类别，不必为它们编一个学习估时。

### Agent说已经处理，但时间线没变化

先看“变化”和“排程后续”。保存规则和挪动时间块是两件事。当前安排已经满足规则、没有新的学习需求、或块都受保护时，可能没有可移动的内容。

可以查询“现在每天怎么安排的”，再从具体块发起调整。不要把“重排”当成必须把每个块都换个位置。

### Agent还是没理解自然语言

先确认有没有带着别的卡片或问题上下文。再用菜单选择 `/调整`、`/查看` 等大类，补一句你希望达到的效果。对象有歧义时，从卡片发起。

这套Agent仍是有限步骤的业务助手，不是每种说法都能处理。遇到失败，保留原句、结果和你期望发生什么，方便修复；不必替它想内部参数。

### 页面刷新后输入内容丢了

未提交草稿目前主要在页面会话里保存。先看是否有“恢复草稿”；已经提交的内容到历史里找。长记录先存在自己的笔记中。

### 邮件没收到

到设置看发信服务是否配置、收件地址是否正确，再看投递记录。也检查垃圾邮件、提醒开关、截止是否已过、安静时段和后台处理服务是否运行。

如果是“恢复后的暂停状态”，需要部署者先核对实例并恢复运行，不能靠反复点发送解决。

## 18. 手机、隐私与数据保存

### 18.1 手机怎么用

直接用浏览器打开自己的实例网址。手机底部有“今天、本周、方向”入口；“本周”按选中日期显示日时间线，更适合小屏。

目前不要依赖原生安卓通知、桌面小组件或离线同步，这些还不是已交付能力。提醒主要依赖配好的邮件服务；断网时不要把“已在输入框写好”当成已经上传保存。

### 18.2 数据在哪里，谁能看到

业务数据保存在你部署的服务器上。一个实例供一个人使用，不需要把同学的信息集中到你的实例里。

调用外部AI时，相关文字、图片和理解请求所需的计划上下文会发给模型服务商；在线检索也会使用配置的搜索服务。按自己的需要选择这些服务和投递内容。

不要把API密钥、邮箱密码、身份证件号码等放进普通对话。部署凭证由服务器配置管理。导出文件也包含私人任务和记录，分享前先检查内容。

### 18.3 导出和备份

在设置的“数据导出”里点“导出全部数据（JSON）”，生成后下载。导出文件保存24小时；过期后重新生成。项目阶段报告可在项目页面生成。

JSON适合带走业务记录。完整恢复实例还需要服务器备份，包括按备份说明保留数据库和相关文件。备份与恢复目前由部署者在服务器操作，网页没有一键完整恢复按钮。

## 19. 一段完整使用示例

下面是使用顺序示例，不保证每次AI都采用同一份方案。例子里的任务名称，需要对应你的真实事项。

**周末，先补基础。**

你导入课表，回答当前教学周；去“本周”抽查两门课。再说：

> 这学期主要目标是巩固数学和编程基础。

> 晚上十点后不排，工作日最多两小时。

系统保存后，你检查作息和目标是否正确。

**接着安排一件学习工作。**

> 明天复习极限部分，预计一小时。

你看它是否进入学习安排。有一个比赛通知也想保留，但还没决定参加，于是从那个事项卡片说：

> 先作为决策事项，不要排学习时间。

**周中，课程负担变得明显。**

> /调整 课多的日子轻松一点，学习安排帮我优化一下。

Agent结合课表和预算决定方案。它可能给临时每日上限并重排，也可能问你主要保数学还是编程投入。你回答自己的取舍，然后检查结果。

**实际学习时，留下反馈。**

你从学习块点“开始”，40分钟后停止计时。记录：

> 今天的基础题做完了，分段函数左右极限还会混淆。极限练习还剩大概一小时。

如果对象不明确，按系统的问题选对应任务。它依据剩余需求继续安排，不把“花了40分钟”自动当成全部完成。

**周末，用结果改下周。**

> /复盘 本周

你发现数学确实有推进，某项目只是反复卡环境，于是决定下周先把数学基础补稳、项目暂缓。把这个决定明确说给Agent，再检查下周时间线。

整个过程中，最需要你提供的是目标、真实变化、关键选择和实践反馈。日常不必为了维护平台而重新整理所有表格。

## 20. 给自己部署的人

普通使用和服务器维护分开处理。先按 [部署说明](./deploy.md) 启动，再回到这份手册。

| 你希望用的能力 | 需要准备什么 |
|---|---|
| 登录、基本页面和记录 | Web服务、持久数据目录、正确数据库版本 |
| 提交后实际后台处理 | Worker服务；只启动网页会让材料一直排队 |
| 模糊指令、材料理解、AI建议 | 可用且兼容的模型端点、模型名、API密钥 |
| 图片理解 | 所选模型和端点实际支持图片输入；纯文字能力不能替代 |
| 在线找资料/项目 | 已配置的搜索服务；当前真实搜索适配器为Tavily |
| 邮件提醒和摘要 | SMTP、发件地址、唯一主人收件地址，加上运行中的Worker |
| 旧Todo/校园来源 | 单独配置的只读桥接；不要给Dash写旧数据的权限 |

网页设置主要调整使用规则、模板和额度；服务连接信息在服务器配置里。密钥不放进仓库，也不通过Agent对话传递。

升级前按实际版本备份；旧镜像和新数据库不能随意混用。有校园桥接时，备份/恢复还要处理那个数据库写入者；旧Todo服务继续保留，不能为了升级Dash把它停掉或改写。

如果实例从备份恢复后显示暂停，这是为了让部署者先确认旧实例已经停下，避免重复发邮件或处理任务。完成部署说明里的核对和恢复操作，再让后台工作继续。

这份手册说明当前怎么用，不等于所有使用情形都已通过真实服务验证。具体能力与未完成验证看 [STATUS](./STATUS.md)；开发者接手看 [START-HERE](./agent-first-v2/START-HERE.md)，产品取舍看 [决策记录](./decisions.md)。

## 2026-10-08 对象选择与降级范围补充（已包含reference-20261008发布）

如果你说“数学别排那么长”但平台找不到叫“数学”的安排，Agent会列出名称和时间让你选。一个任务分了几段时，也会问你指哪段；答“第二个”或完整时间选项即可接着办，必要时仍会请你确认修改。某段在等待中已经完成或改了，它会拒绝旧选择，请按当前事实重说，不会悄悄改另一段。


## 最新开发补充：AI没听懂或超时怎么办（待上线）

如果这次AI请求超时，你的话会保留下来，并告诉你哪部分没有办成。系统不会把“调整设置”等要求擅自变成一项任务。可以在失败结果上点重试；它会重新理解没有办成的部分，同次已经成功的改期不会再做一遍，调用预算也不会清零。独立上传的文件仍可继续处理，所以一条消息也可能有部分成功、部分失败。生产当前版本请以[STATUS](STATUS.md)为准，该行为已随budget-20261008发布。

### 用聊天调整 AI 调用额度

可以说“把模型额度调到一千次”。如果没有说按每天还是其他周期，Agent 会先问。当前额度按每天的调用次数计算，不是金额。

回答“按每天”后，先看确认卡：例如“每日模型调用上限：150 → 1000 次（长期，每天重新计数）”。确认前额度不变；说“可以”或在卡片同意后才保存。拒绝就保留原值。如果你在另一台设备改过额度，旧确认会失效，系统按新值重新让你确认。Agent 不会因为你说“优化安排”就自己提高额度。具体生产版本见[STATUS](STATUS.md)。

### 本地新改进：没带链接时可以接着补（2026-10-09，尚未上线）

如果你说“这个链接放到科研项目下”，却没有贴实际链接，Agent会请你补链接。贴完整HTTP或HTTPS链接后，它接着处理原来的关联；项目没对上时会列出真实项目让你选。最后看清确认里的链接、资料类型和项目，再说“可以”。这只把资料存下来，不会把它变成学习任务，也不代表已经读过网页全文。

同时，你在等待确认期间从别处改了资料，旧确认会作废，Agent需要按当前内容重新确认。这段是本地开发说明，生产是否包含以STATUS最近部署记录为准。
